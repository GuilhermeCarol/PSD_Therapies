# Recursos 3D do pack — medo de agulhas (protótipo)

Nomes previstos neste pack:
- `consultorio.glb` — espaço 3D da consulta.
- `medico.glb` — personagem virtual com rig/animações, se disponível.
- Outros recursos GLB/glTF e texturas referenciados pelos modelos.

Neste momento **não foram adicionados modelos 3D**, apenas estão reservados estes nomes no `manifest.json`.
O Godot ainda **não carrega automaticamente** estes recursos a partir do pack descarregado; a integração da cena 3D será uma etapa posterior.

Formato recomendado: GLB, com materiais e recursos incluídos. Não colocar aqui scripts.
Os packs são atualmente descarregados através da API GitHub Contents e têm um limite de 80 MB; modelos grandes exigirão outro método de distribuição.
